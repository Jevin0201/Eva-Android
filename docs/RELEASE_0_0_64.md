# Eva Android 0.0.64

更新日期为 2026-11-06。本轮按用户最新要求停止抓包验证，收尾范围限定为 Eva 项目、打包和保留数据覆盖安装。

## 合入安装包的调整

- 输入区整合工作区入口、状态提示和上下文用量展示，保留停止与引导入口。
- 完整访问权限按会话及回合生命周期管理，发送失败、任务中断和进程重启后撤销临时决定。
- 发送内容先持久化再分发，异常时保留草稿。启动与导航恢复区分未确认发送、运行状态和已结束回合，避免自动重放。
- 恢复旧会话时通过独立历史投影升级原生工具定义，保留原始历史和自定义工具。
- 网络工具增加自动准备、系统授权后继续、目标 App 限定、结果导入与连接诊断。修正后台运行授权、停止后的写入等待、超大 HAR 对事件摘要的阻断及采集收尾。
- 延续 0.0.63 的 Java 21 和 Ghidra 修复，具体真机证据见 `JAVA21_GHIDRA_20261106.md`。

## 抓包能力的实测范围

通用 HTTPS 样例通过自动采集、停止、导入及响应正文读取。美团原版取得部分配置接口的 HTTPS 明文，同时记录到多个接口拒绝代理证书。经用户同意准备的独立测试副本可启动并解密大量响应，但外卖业务请求返回 403，正文指向请求签名校验。商品名称、价格、规格对应的业务接口验收尚未通过。用户已要求暂停此项工作。

本版本的自动准备和结果分析改动可随 Eva 安装，不据此宣称美团商品接口或任意 App 的 HTTPS 解密已经交付。第三方抓包组件保持独立安装。
