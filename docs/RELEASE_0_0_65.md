# Eva Android 0.0.65 性能与缓存清理

2026-11-06，按用户要求清理手机 Eva 缓存并优化本地响应。

## 定位与处理

清理前，WebView HTTP 与代码缓存占用 114601 KiB。确认实际绝对路径位于 Eva 私有缓存目录后，短暂停止应用并删除该缓存目录，剩余缓存为 94 KiB。升级备份通过 SQLite 完整性检查。

真实 UI 快照总量为 19234660 字节，当前会话为 96905 字节。原先流式更新每 500 毫秒及草稿自动保存会序列化整份 UI 数据，重复传输其他历史。

- 流式事件和上下文用量更新按发生变化的会话排队，复用原有事务检查点及完整索引。
- 草稿自动保存复用同一队列。保存尚未完成时合并后续更新，避免持续积压快照。
- 未知结构变更及无法增量保存的旧数据继续使用完整快照回退。
- 切换后台立即刷新待保存内容，覆盖尚未触发防抖计时器的最后输入。
- 打开历史后的状态保存延后执行，使界面绘制优先完成。

## 验证

最终包已保留数据覆盖安装，版本 0.0.65、版本码 65。包内脚本与源码一致。

真机 WebView 使用独立的模拟历史进行对照，18 MiB 未更改历史加当前会话和草稿。9 次采样中，完整序列化中位耗时 36.8 毫秒，当前会话检查点构造 4.1 毫秒，传输字符数由 18985309 减至 110884，减少 99.4%。该对照衡量 JavaScript 序列化及检查点构造，不代表完整模型任务的耗时比例。

独立原生 SQLite 基准使用 18 MiB 未更改历史与短草稿。完整快照保存中位耗时 679 毫秒，当前会话保存 2 毫秒，旧历史及新草稿均完整回读。临时数据库已在检查结束后删除。

最终包的 541 片段流式渲染检查通过，无空白帧、内容回退、节点重建或阅读位置漂移。帧间隔 P95 为 85.5 毫秒。

前端回归覆盖多会话保存、完整索引、慢保存合并、草稿防抖、完整快照回退、后台最后输入、停止和引导、连续流式持久化、重启恢复、上下文压缩与 Android 返回。

升级前后 31 个 UI 快照摘要全部一致，SQLite 完整性检查通过，28 个聊天、2 个草稿和 1 个项目数量一致。证据保存在 `artifacts/performance-0.0.65/`。
