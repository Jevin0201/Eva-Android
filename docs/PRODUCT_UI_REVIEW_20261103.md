## 实现位置

- `probe/assets/product-ui.css`：最终加载的产品样式，避免重排各功能脚本。
- `probe/src/ShellActivity.java`：将产品 CSS 纳入本地资源明确白名单；保持网页桥接边界。
- `probe/src/EvaUi.java`、`ToolPageActivity.java`：共享原生控件。
- `PhoneControlActivity.java`、`VoiceActivity.java`、`BrowserWindow.java`：页面局部调整。
- `settings.js`：动态分组标题 HTML 转义。插件特殊名称回归先失败，修复后通过。

## 证据

`outputs/product-ui/` 保存浏览器截图、实际手机截图和 `layout-results.json`。浏览器截图使用本地 fixture，不代表登录、云模型调用或原生工具运行成功。真机截图只验证可展示内容；没有触发语音监听、VPN 采集或依赖安装。

本轮现有回归：settings-ui、sidebar-ui、model-panels、extension-lists、plugin-manager、skill-manager、mcp-settings、task-controls、voice-ui、composer-references、keyboard-ui，共 11 套通过。

APK：`outputs/eva-android-0.0.32-ui-review.apk`。沿用开发版版本号，作为 UI 检查包，非正式发布。Java 编译存在既有 Java 8 / deprecated API 警告。
