# 0.0.19 项目、对话和文件流程

## 已实现

- 对照桌面 `src/renderer/composer.js` 的 `openModelMenu/openModelList/selectProviderModel`：先紧凑控制卡，点击模型名打开独立列表，选择立即保存；推理强度滑条、默认重置、快速模式；切换提供商保留旧对话并回到新对话。运行中禁止更改。手机采用底部面板容器。
- 侧栏项目入口，创建独立项目目录、项目内新建对话、默认工作区入口。项目名称不参与磁盘路径；使用 UUID。thread/start 和 resume 将项目目录传入内核 cwd，由原生层检查目录边界。
- 输入区加号提供照片／文件入口。Android 13+ 优先系统照片选择器，其他情况使用 SAF 图片选择；文件使用 ACTION_OPEN_DOCUMENT。仅复制用户选中文件，单次 10 个、单个 32 MiB。
- 附件按对话保存，可移除；导入结果持久化、幂等接收；取消不清空草稿。照片以 Codex localImage 输入发送；其他文件作为工作区路径交给内核。发送失败保留附件，成功后移出待发送区，磁盘原件保留。
- 文件预览标题栏“另存到手机”：ACTION_CREATE_DOCUMENT 保存到用户选择位置，支持二进制流复制；不要求全部存储权限。
- 权限页解释选择授权、复制、发送和保存的范围。
