# 0.0.3 界面移植记录

已把用户确认的 HTML 视觉应用到安卓首页、侧栏、会话草稿和任务列表。布局/CSS/SVG 来自本项目 outputs/ui-preview，其桌面来源哈希见 source-reference.json。

呈现采用 APK 内置 HTML/WebView；执行与权限保持原生 Android。页面只从 eva.invalid 的两个内置资源加载；所有其他资源请求被阻断，顶层跳转被拒绝。远程浏览器是单独 WebView，不注入 EvaHost。接口仅提供本机 UI 状态存取、受限任务读取以及固定工具页导航，不提供网页任意执行命令接口。

示例任务/文件/账号均已移除。任务列表读取真实 state.json。未配置模型时仅保存待发送消息，不伪造助手响应。旧原生试验会话保留原存储未删除，但尚未迁移至新界面，正式升级前需补迁移。

已验证：构建、签名、真机安装启动；首轮截图发现状态栏重叠后改为容器安全区。PC 浏览器使用模拟原生接口，验证草稿保存、会话保存、任务内容转义、设置和详情接口路由通过。该模拟不代替 Android 桥接及软键盘全路径验收。

设置、文件、浏览器和终端目前打开已有原生页面，尚未完成所有二级页面与 HTML 设计统一；任务详情暂显示原始状态。云模型和跨 App 控制仍未实现。
