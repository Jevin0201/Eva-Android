# 页面层级返回修复（2026-11-17）

## 原因与改动

`android-navigation.js` 原先将每次 `settingsGo` 的前一页面压入 history，把插件/技能/MCP 标签、同级设置切换也当作下一层。返回因此回放操作历史。

替换为页面上级入口记录。插件、技能、MCP 归为同一扩展模块，切换标签不增加层级；从对话直接进入返回原对话，从设置进入返回设置。普通同级设置页共享上级，重复打开和刷新不新增返回层级。系统返回和页面箭头共用同一退出逻辑。

保留键盘、弹窗、图片预览、插件详情及任务详情的独立退出行为；已编辑内容的原确认继续保留。退出模块时释放扩展菜单状态，修复旧插件详情状态可能错误影响 MCP 返回。浏览器网站内导航和编辑器撤销不是此次设置历史栈，不将它们改为模块退出。

## 验证

`test-android-navigation.cjs` 通过直接入口、设置入口、多次往返标签、同级设置、系统返回函数、页面箭头、键盘、弹窗、图片预览、同一会话和任务页检查。`test-extension-full-ui.cjs` 通过共用添加菜单、弹窗和目录刷新保持菜单回归。

构建沿用 0.1.3 验收包独立签名，目标仅 `ai.eva.android.acceptance`，正式包不变。安装包 `artifacts/device-acceptance-20261117/Eva-0.1.3-navigation-acceptance.apk`。

## 清理

复用已有构建目录，本轮只新增必要测试、文档、验收记录及交付包；未删除既有源码、签名、依赖与未知历史资料。已检查，无需清理。

## 真机结果

已保留数据覆盖验收包。设备 509655c7 实测 Android 返回键、屏幕右边缘向左滑返回手势、页面返回箭头，反复切换扩展标签后均一次返回原对话；从设置进入则返回设置，再返回对话。普通设置页切换不回放历史，当前会话标识前后不变。结果在 `artifacts/navigation-hierarchy-20261117/device.json`。所有本轮 ADB 转发已移除。
