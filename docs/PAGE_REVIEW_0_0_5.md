# 全页面审查与修改：0.0.5

日期：2026-11-02。基于本项目实际源码和已确认 HTML 的导航结构，不修改桌面 Eva。此版本是页面与操作路径的改进，不是完整手机代理交付。

## 页面职责和本轮修改

| 页面 | 应承担的操作 | 本轮落地 | 仍需完成 |
|---|---|---|---|
| 首页 | 开始任务、恢复草稿、进入本地工具 | 明确模型未连接；空输入禁用；保存待发送用文字按钮；修正窄屏输入栏挤压 | 真实发送、附件、键盘/旋转专项验证 |

| 抽屉 | 搜索与切换会话，进入工具与设置 | 标题与消息内容搜索；最近/归档切换；搜索空态 | 大量会话性能、旧原生存储迁移 |

| 任务详情 | 查看命令、退出码和输出 | 从原始 JSON 弹窗改为独立页；stdout/stderr 分开；记录更新时间、工作目录、错误、截断提示；返回列表 | 开始/结束时间需运行器补字段；详情取消按钮需可靠任务控制接口 |

| 工具与权限 | 区分系统授权与服务可用性 | 保留真实的未实现状态及系统应用设置入口，避免虚假授权开关 | 无障碍、截图、网站权限尚未接入；本轮未实现这些服务 |
| 任务设置 | 调整后续命令的超时 | 30/60/120/300 秒接入真实配置；真机验证配置落盘 | 前台服务、通知、后台保活与中断恢复 |
| 浏览器设置 | 设置启动页 | HTTPS 输入校验；修订能力说明 | 多标签、重启恢复、权限和数据管理 |
| 工作区与存储设置 | 查看空间并进入文件/终端 | 展示本机可用空间、根文件系统导入状态，独立入口 | 环境自主初始化、导入/导出、空间管理 |
| 外观 | 调整界面颜色 | HTML 和重新打开的本地工具支持深浅色；网页自身内容不强制变色 | 全局主题实时同步与原生系统弹窗一致性 |
| 关于与诊断 | 版本与运行环境排障 | 更新为 0.0.5，保留真实环境诊断入口 | 旧 MainActivity 仍是技术诊断页，未重做为用户报告；日志脱敏与导出未完成 |
| 工作区文件列表 | 进入目录、返回、定位文件 | 目录优先排序；逐级导航；当前路径；空态和错误态；canonical 路径边界检查；左对齐列表 | 长列表分页、搜索、导入/导出、滚动位置恢复 |
| 文件预览 | 安全查看文本并返回原目录 | 独立只读页面；UTF-8 严格解码；二进制/超过 256 KB/编码错误提示；文字选择 | 编辑、图片/PDF 等预览、分享、关联会话 |
| 内置浏览器 | 浏览及恢复导航上下文 | 地址校验、前进/后退/刷新/停止、进度、网络/HTTP 错误；切换本地工具不销毁网页；无远程网页原生桥 | 多标签、上传下载、任务浏览器控制；Activity 销毁后不保留页面；网页成功加载未纳入本轮断言 |
| 本地终端 | 执行、观察、停止命令 | 输出刷新限频至约 100ms；中文结束状态；执行失败状态；运行中切换有提示；返回可发出停止请求 | 前台服务、停止最终状态专项回归、实时 stdout/stderr 分栏；历史仍使用原生列表 |

## 验证与限制

- `tools/test-shell-ui.cjs`：模拟原生接口测试空提交、草稿、改名、归档/搜索、45 条任务分页、详情输出转义、设置返回、320/390/600 宽度，通过。
- `tools/test-settings-ui.cjs`：七个设置子页、超时、启动页、主题和返回，通过。该脚本是浏览器模拟接口测试。
- APK 通过 Java 编译、DEX、打包、签名验证，覆盖安装到已连接手机，版本 0.0.5。
- `PageCheck` 使用真机 Instrumentation 和真实桥接，检查设置落盘、HTTP 拒绝、目录/预览/返回/二进制路径、浏览器实例保留以及页面截图。测试会恢复会话与设置，清理临时文件；不会把测试会话留给用户。
- 手机对 Instrumentation 自行启动 Activity 曾返回 102 导致等待；用 ADB 显式启动本应用后完成测试。不是产品功能已失败或已通过的替代证据。
- 截图与测试结果保存于 `artifacts/pages-0.0.5/`。截图使用测试会话/文件；浏览器截图仅说明加载界面，不能证明完整网页代理可用。
- 页面层仍为 APK 内置 HTML/WebView，本地执行和工具为 Android 原生代码。原生工具视觉尚未完全统一到 HTML 列表样式。
