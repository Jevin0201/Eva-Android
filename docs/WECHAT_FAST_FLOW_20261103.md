# 微信固定手机流程（0.0.32）

面向当前 M332BF 手机、1280×2772、520 dpi、微信 8.0.79 的独立适配。模型继续云端调用，步骤在手机原生工具中批处理。不是通用安卓坐标，也不是模型权重训练。

## 接线

`PhoneTools.specs()` 注册 `eva_wechat`，与普通手机工具共用串行执行器、会话所有权、停止控制/锁屏/任务中断检查。新对话获取新工具定义；旧内核会话可能保留旧工具声明，首次使用应新建对话。原手机工具保留。

- `status`：验证设备、显示、微信版本、本地中文 OCR、Shizuku。
- `open_chat(recipient, instance)`：默认主微信 user 0；只有用户明确指定分身才用 user 999，不以主微信替代失败的分身。
- `prepare(recipient,text)`：搜索、唯一精确结果、核对标题、整段 Unicode 输入并核对，不发送。
- `send_message(recipient,text,requestId)`：同上，发送前核对原文；持久化发送尝试，提交一次，确认新增匹配气泡、草稿清空、无可见红色失败标记。同 requestId 不重放；不确定结果不可换编号自动补发。
- `read(recipient)`：核对标题，只 OCR 聊天区白色/绿色消息气泡，返回方向、位置、置信度、可见消息及相对上次的增量。首次读取是可见历史；OCR 波动/表情包不是可靠新消息信号，不自动开启回复循环。

## 固定动作与核验

直接系统启动所选微信；从受支持的聊天/搜索/资料页恢复到消息首页；标定坐标打开搜索，整段提交姓名，本地结果自动刷新，不按可能进入搜一搜的键盘搜索按钮。局部 OCR 识别唯一精确联系人/群聊；忽略聊天记录/收藏/视频号等后续分区；同名歧义停止。进入后核对聊天标题。输入用 Android 无障碍 IME `commitText` 整段提交，不模拟逐字键盘、不借用电脑剪贴板；能完整获取输入连接内容时直接比较，否则用输入栏局部 OCR。灰色搜索提示不是草稿；已有真实草稿不覆盖。优先使用编辑器 SEND 语义动作，否则定位当前实际“发送”文字控件，不把右侧头像当按钮。

前台被切走、主/分身不符、显示设置变化、控件未生效、草稿无法核验时停止，不沿用旧坐标。首页上方浮窗可能拦截点击，因此前台 Activity 检查仅能阻止后续跨应用操作，不能证明无浮窗；遮挡仍需恢复后再执行。

## 图片和依赖

模型不接收本工具的屏幕图片；局部识别图在 Eva 私有 rootfs tmp 生成，Tesseract 完成或异常时 finally 删除；进程强杀遗留的自有临时图在下次流程中清理。没有 MediaStore/相册写入。本轮不清理早先模型自行写在 `/sdcard/eva_*.png` 的文件。

复用手机已安装的 Alpine Tesseract 和 chi_sim/eng 数据，没有下载第三方代码或增加 OCR SDK。未初始化 OCR 时明确报告缺失，不在发消息任务中临时安装。该适配尚不负责首次 rootfs 自助初始化。

## 验证记录

纯 Java `WechatPolicyTest` 25项通过，覆盖精确姓名、群人数后缀、标点差异、显示/版本失配及消息序列重叠。Android APK 编译、签名和覆盖安装通过。真机正式模型通道已能调用 `eva_wechat status`。正式模型（手机当前 DeepSeek）真机验收通过：一次 `send_message` 完成文件传输助手新消息发送与气泡核验，耗时24,101ms，5次本地取图、9次局部OCR、6次输入连接读文本，0张图片附给模型、0个相册文件。同 requestId 重试2ms即拦截，不再发送。“小白”短姓名读取通过；再次读取返回 `firstRead=false,newMessages=[]`，耗时15,718ms。25项策略检查通过，APK签名与覆盖安装通过，原6个会话保留，私有OCR临时文件余量0。最终只读回归使用最终APK；发送验收后修改仅为白色卡片方向与短姓名OCR后备路径，未再次向联系人发消息。证据：`artifacts/wechat-integration-20261103/acceptance-summary.json`。

已覆盖故障：搜索提示文字误判、消息输入连接不可完整读取、键盘收起后的裁剪区域、OCR稀疏模式漏短姓名、无效等待负数、前台切走、重复请求。Android覆盖安装后无障碍重连可能需要十余秒；未就绪时报告控制未开启，不自行绕过。当前实测并非100%成功率承诺：表情包、长草稿、浮窗遮挡、未知布局仍可能停止；微信分身 user999 路径有实现，但本轮未真机发消息验收。

桌面外置 ADB 实验的 8.94 秒零截图数据、17.67% 草稿脚本提速都不等于本次手机原生工具或完整模型任务耗时，必须分别计时。
