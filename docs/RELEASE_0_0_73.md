# 0.0.73 模型管理与提供商折叠选择

2026-11-08。对照本机布噜发布代码后重构 Eva 的模型状态与配置。参见 [审查依据](MODEL_MODULE_BULU_REVIEW_20261107.md)。没有复制布噜代码。

## 行为与修复

- 前台模型按钮保持原有样式。模型列表按 OpenAI、各 API 提供商分组，可展开与折叠，当前项有勾选和提供商标题提示。手机现有配置实际顺序为 OpenAI、DeepSeek、本机免费模型。
- 提供商连接、测试模型、完整目录、手动模型、显示偏好、全局默认、当前会话及新会话草稿分别保存。连接测试模型不会混入目录。明确隐藏的模型不会通过旧配置重新出现。
- 打开、刷新、关闭或折叠菜单不写入模型选择。全局默认只作用于新会话，已有会话保留自身模型。更改提供商、目录或默认值不会批量改写历史对话。
- 删除提供商后原会话明确显示不可用，仍可打开选择器重选。保存失败回滚并提示，按钮标题按当前提供商和模型显示。
- OpenAI 目录全量分页，按账号身份隔离缓存，拒绝过期异步结果和循环游标。账号模型也可管理显示、设置新会话默认。
- 模型推理强度、图像和工具能力使用已提供元数据，不再默认编造所有模型均支持。图片附件显式传给内核，已明确不支持图像的模型会保留草稿并阻止误发。
- API 添加可明确选择 Responses 或 Chat Completions。Chat 通过手机内标准库网关适配内核，支持流式输出、图片、函数及嵌套命名空间工具、多回合工具结果匹配、唯一调用编号和错误返回。Chat 提供商关闭专属 Responses 托管搜索，保留 Eva 浏览器工具。
- 名称、显示偏好、目录及默认值变更不要求整机重启。连接更改或新增提供商在内核空闲时自动刷新。执行中保留任务并推迟连接重载。前台收到刷新事件只清除对应加载缓存，保留聊天内容。
- 本地免费服务仍通过既有受管理启动与私有凭据接入。模型连接页面增加目录发现、文本连通和连续三轮工具检测。
