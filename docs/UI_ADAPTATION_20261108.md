# 侧边栏与设置 UI 适配

用户确认：对话页面不用改；侧边栏、设置与子页可以调整，必须保留功能适配。

## 实际改动

- 侧边栏继续使用原有项目/会话渲染、折叠、左滑删除、项目管理和草稿状态，增加现有搜索对话入口，底部增加工具与工作区入口。没有引入新的会话存储结构。
- 设置重新分为连接与能力、偏好、更多；保留原有全部入口，并直接提供语音入口。超时、浏览模式与启动页仍调用原生配置保存。
- 新增末尾加载的 `probe/assets/settings-refresh.css`，限定侧边栏、设置返回按钮所属页面、扩展管理和明确标记为设置来源的面板。未修改全局主题 token、对话渲染和输入框样式。
- `modelPanel` 只增加设置来源标记，沿用原有关闭、返回、事件和异步状态逻辑；从对话打开的面板不应用设置样式。
- 原生模型、账号、组件、手机控制、备份、定时任务通过限定的共用视觉方法统一按钮、输入框；语音和 MCP 凭据页单独适配。保留真实 Switch、输入类型、密码保护、FLAG_SECURE、点击事件、权限与持久化调用。语音服务状态仍由原机制驱动。
- 原生输入框在加入页面后仅应用一次视觉样式，不重建或替换控件；后续状态回调、焦点与输入内容不由样式层管理。

## 后续修订：侧栏精简与分组折叠

按用户最新要求，移除侧栏搜索对话和底部工作区，底部只保留工具、设置；技能与插件入口保留。工作区仍可从工具或设置中的存储入口访问，搜索处理函数保留兼容，但侧栏不再显示入口。HTML 评审稿同步移除两个入口。

原折叠路径会同步保存完整会话数据并重建整个侧栏。改为仅更新目标分组，保留触发按钮、其他项目、滚动容器及会话节点。首次展开初始收起的分组时才创建该组内容；已渲染的内容折叠后使用 hidden/inert 隐藏，不销毁。180ms 高度/透明度动画支持连续点击反向打断，减少动态效果偏好下立即切换。原左滑、删除、项目管理和会话点击事件继续使用现有委托。

折叠状态立即写入内存，保存合并延后 260ms，页面隐藏/离开时刷新；有 saveLater 时使用原生异步保存接口，旧宿主回退原 persist。兼容原 sidebarState 格式，没有新建存储协议。完整侧栏渲染时先一次分组会话，避免每个项目重复筛选全部历史。

回归通过：侧栏节点/焦点保留、连续反向折叠、无同步保存、延后保存、pagehide 刷新、减少动态效果、移除入口、草稿/项目归属、工具/设置导航；项目管理、Android 返回和对话样式/布局隔离回归通过。结果来自本机 Chrome 模拟宿主，尚未安装新版 APK 或验证真机流畅度。

清理检查：本次没有新增可删除临时文件。回归截图更新于既有 artifacts/sidebar-0.0.21/ 和 artifacts/ui-adaptation-20261108/，作为证据保留；旧安装包、构建和用户数据未动。


## 后续修订：默认模型页内选择

“账号与模型 → 设置默认模型”原先错误地绑定 model-manage，导致用户进入供应商管理。现改为带供应商分组的页内 select，直接列出本机已配置的模型目录、手动模型及已知且已登录的账号模型。不发起目录网络请求，不显示新增供应商选项；供应商管理入口仍留在独立分组。API 模型目录为空时兼容原先单独配置的模型字段。

按供应商 ID 与模型 ID 组成唯一值，避免不同供应商使用相同模型 ID 时选错。通过原有 EvaHost.modelDefault / ModelStore.setDefaultSelection 保存并读回确认；失败回退原选项，空目录禁用选择并显示原因。仅影响新会话，保留当前会话、草稿和当前输入框的选择；切换到另一模型时不携带旧模型的推理档位和服务档位。同模型重存保留现有档位。
