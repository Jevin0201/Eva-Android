# 工具页面重设计与桌面兼容（0.0.9）

2026-11-02。根据用户纠正，终端、文件、浏览器各自独立设计，不再共用三个标签。侧栏顶部提供并列入口。

## 页面变化

- 浏览器：56 dp 顶栏、胶囊地址栏、地址栏内桌面/手机标记、菜单；2 dp 加载进度；52 dp 底部图标导航。刷新与停止复用同一图标；不可用的前进/后退置灰。菜单提供模式切换、复制网址和网页信息。网址支持键盘“前往”。加载成功不保留大块状态栏。
- 终端：紧凑标题栏包含停止和历史；目录与状态单独一行；主要空间用于可选择的深色等宽输出；命令输入固定在底部，运行按钮为圆形图标。空命令/执行中禁用运行，停止与历史按执行状态启停；保留草稿。
- 文件：紧凑标题与刷新；路径栏、当前目录搜索、项目数量；文件列表用图标、名称、大小/日期组成两行。支持搜索空态、目录层级返回，进出预览时恢复当前 Activity 内的列表位置。预览使用文件名标题，不再用大按钮占据顶部。

## 桌面兼容证据

使用 AndroidX 官方 WebView 扩展接口配置 User-Agent Metadata，并在文档最早阶段安装兼容脚本。默认桌面模式同时调整普通 User-Agent、Client Hints、navigator.platform、屏幕信息及宽视口。移动模式恢复原始 metadata 并移除文档起始脚本。

真机受控页面读取到 Linux、x86、64 位、mobile=false、model 空字符串。受控 HTTPS 请求在 WebView 请求拦截点观察到 User-Agent 为 Linux x86_64，sec-ch-ua-mobile 为 ?0，sec-ch-ua-platform 为 Linux。页面自己的首段脚本读取到 Linux x86_64 和 1280 屏幕宽度。

这些证据是常见桌面识别信号的一致性验证，不是所有网站数据可见性验证，也不是设备指纹不可检测保证。GPU、字体、Worker、媒体查询、内核能力等未全面仿真；实际仍是 Android WebView。不得宣称已经变成完整桌面操作系统或可对所有网站隐藏设备。

依赖、许可证和精简构建范围记录在 research/androidx-webkit/README.md；Apache 2.0 许可证与归属通知打包在 APK assets 中。
