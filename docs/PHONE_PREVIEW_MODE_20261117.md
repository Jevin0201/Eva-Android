# 手机预览执行屏切换与设置保持

预览顶部仅保留循环双箭头、最小化、关闭三个按钮；移除 Eva 标题。顶部空白及底部状态区可拖动。箭头使用无障碍描述提示目标执行屏。

前后台选择是当前运行状态，后台屏与预览开关是用户保存的偏好。模型 foreground、preview 和停止控制不再覆盖后台屏/预览偏好；用户明确关闭开关仍有效。切换在手机工具串行队列执行，保留任务归属与取消代次，通过 Shizuku 移动已有应用任务后切换执行屏。空屏可切换，不移动 Eva 主界面到后台屏。
