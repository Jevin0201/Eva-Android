# Eva 内置浏览器恢复与控制

依据手机 0.1.2 的历史：兼容打开、观察、点击有成功回执；高级只读 Page.getFrameTree 约 47.4 秒失败，结果为空。无法从历史确定这条调用在哪一层卡住。源码另有确定的整轮中断路径：用户触碰、导航或关闭浏览器会发送 turn/interrupt。这两项分别处理。

- 默认首个浏览器操作显示前台窗口。同一回合内最小化、展开以及后台切换标签不会抢回显示。
- 同页手动操作使旧浏览器租约失效，取消其等待中的操作。对话提示有「继续网页任务」，窗口也可交回控制。浏览器操作等待交回；无副作用的读取可重做，已经可能发出的写操作必须先核对。
- 明确关闭或渲染进程退出后撤销旧租约，保留聊天回合，自动尝试重开最多两次。正常关闭尽量恢复当前标签的 WebView 历史；不保证恢复其他标签、未提交表单或崩溃后的页面状态。显式停止任务取消等待及未执行的重开。渲染回调区分崩溃与系统终止，未知根因不猜测。
- 高级调用区分宿主状态、端点发现、连接、标签匹配、命令回执。短超时包住发现及标签探测，常用只读工具失败重试一次，仍失败会带阶段原因。失去回执的写入不会自动重放。若内核回合结束但没有明确的最终答复，对话提示结果未确认。
- 在授权登录场景允许对快照对应的密码框输入；观察不返回密码框值。文件选择保持原机制。

能力来源为本仓库从桌面 Eva 迁移的 browser-control/bulu：语义快照、编号、检查、动作和批量执行。已有来源清单见 migration/desktop-browser/SOURCE.json 与 bulu/port-manifest.json（运行时在 probe/assets/desktop-browser/browser-control）。本轮接通 Android 宿主并改进工具使用说明，未下载或安装独立的布噜 MCP、Chromium 或新增第三方代码。修复目标为内置 WebView。

验证：Java 全量编译；浏览器工作进程在隔离本机浏览器模拟端点故障并恢复，后续真正调用 Page.getFrameTree、快照、密码输入及批量点击；页面点击计数一次，密码未出现在随后快照；标签、桌面视口、对话继续/停止、缺少最终答复提示的回归通过。隔离 WebView handover 验收源码已更新，未运行手机真机验收。没有覆盖安装，没有操作用户正在执行的任务。
