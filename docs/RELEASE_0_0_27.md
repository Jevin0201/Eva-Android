## 手机识别
- 根窗口读取失败时，从活动/焦点应用窗口寻找备用根；空树以 200ms 间隔最多重试 3 次。
- 树不足以提供文字时附带截图；独立 screenshot 也返回可供 gesture 使用的新快照。不能再把根为空直接等同于“无法操作”。
- 增加 resourceId、hint、selected、checked；最多 500 可见节点、1500 次访问、180ms 遍历预算，避免大树长时间占用主线程。
- 点击文本节点时向上寻找最多 6 层可点击父控件；滚动同样寻找可滚动父控件。
- 屏幕窗口变化或停止控制使视觉操作快照失效；保留锁屏与密码控件限制。
- 截图缩放和 JPEG 编码改到专用线程；最长边 1920、质量 75，改善小字清晰度。受保护页面截图失败时明确报告，不绕过系统限制。
- 扩充工具说明，要求缺少节点时尝试截图、坐标操作或 App 搜索入口，不能据空树断言联系人不存在。
- 自有 PhoneFixture/PhoneSelfCheck 增加不可点击文字子节点→父控件点击场景；需真机执行，尚未验证。

## 信息流
- explicit final_answer 才是运行中的最终回答；未标 phase 的消息，仅在终止状态下推断末尾文本为最终回答。
- 最终回答出现后可折叠处理过程；失败/中断不强制折叠，失败项独立保留。
- 紧凑工具状态行、按需挂载输出、输出展示上限、Markdown 缓存、空最终回答区域不占位。
- 已保存模拟截图 artifacts/flow-0.0.27/{collapsed,expanded}.png；不是手机截图，也不是微信任务成功证据。

## 性能
- 流式与输入草稿保存走 native saveLater 专用单线程，版本号淘汰过时写入；关键发送/删除仍同步确认保存结果。写入失败通过事件提示。
- 内核事件队列使用独立锁，避免内核启动、配置读取、进程创建持有的锁阻塞 UI drain。
- 保留 0.0.26 的批次刷新、复用会话、稳定 DOM、失败草稿恢复。
- 没有修改云端模型推理或网络速度；不能承诺消除首 token 等待。
