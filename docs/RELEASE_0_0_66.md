# Eva Android 0.0.66 手机执行与网页交接

2026-11-06。根据 Mika 对比分析，实施后台虚拟屏、通用多步操作、浏览器控制权交接。保留 Eva 现有 Codex 内核和信息流。

## 使用入口

手机控制页新增“在独立后台屏操作 App”和“查看后台画面”。需要先开启手机控制、授权 Shizuku，系统为 Android 14 或更新版本。开关默认关闭，当前进程内生效。停止手机控制释放后台屏，页面采用固定 1080 × 1920 的独立执行尺寸。创建失败显示原因。

后台屏启用后，既有 eva_phone 的 App 启动、观察、节点点击和输入、手势、截图及返回/主页按键使用该屏。观察返回 displayId。无节点编号的 IME 输入需要改用可编辑节点。微信专用流程和任意 Shell 命令要求切回主屏。后台屏断连会拒绝继续操作。

模型工具新增 eva_phone_steps，支持 1 至 20 步。目标以精确文字、resourceId 或描述匹配当前新观察，必须唯一。支持 expect、expect_gone、expect_package、before_package、wait_stable 和 timeoutMs。每步等待最多 10 秒，整批预算 60 秒，已开始的单个底层动作仍受其原有超时控制。任一步失败、输入回读不符、未预期 App 切换、取消或用户插话时停止后续步骤，返回每步结果和最后观察。动作不自动重放。派发进入 UI 队列后仍会复核插话修订号。已有会话通过原有工具定义升级投影更新。

浏览器按 thread/turn 独占当前页面，另一任务不能抢占。用户触摸网页、地址栏或手动导航会立即收回控制并中断任务。收起浏览器保留页面及任务，真正关闭窗口会取消并释放。完成、中断、内核退出时释放租约，异步观察和 JS 回调复核租约及窗口身份。
