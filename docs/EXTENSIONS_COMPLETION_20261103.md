## 本轮修复的验收问题

- Android WebView 新模块均加入资源名单，不能只打入 APK。
- MCP config/read 返回的 nullable 默认字段不能直接写回 TOML，回写去除 null。
- config/read 保持原生原始值，禁止直通 JS；否则先脱敏再写会损坏凭据。其他响应继续脱敏，凭据在启动及更新时注册到过滤器。
- Android 系统的 `/data/user/0` 目录别名先规范化，再检查应用目录内部链接；避免误拒绝合法记忆目录。
- 浏览器测试页需设置原生 history URL，不能用 about:blank 的页面假冒 HTTPS 文件来源。
- 设置入口统一到“技能与扩展”，避免每个模块重复单独分组。

## 明确未完成的部分

- 云端应用连接相关插件仍受账号授权、服务端能力和手机宿主限制；保留 apps=false，未把全部桌面插件宣称为 Android 可运行。plugins/remote_plugin 已启用，发现预取仍关闭。
- 第三方 MCP OAuth 完整授权、失效刷新与第三方服务真实业务调用尚未验收；stdio 环境变量密钥编辑未补齐。
- 插件更新通过来源升级，缺少独立回滚与兼容性检测；依赖安装、ARM64 二进制兼容并不由“安装成功”保证。
- 浏览器上传 helper 注入的是系统选择器返回值，验证了真实 WebView 文件读取，未声称第三方网站完整上传成功。摄像头/麦克风正向采集、长流网络中断、blob/data 下载、断点续传、多标签及跨进程下载恢复未完成。
- 历史备份不含工作区文件、附件、账号/API凭据和运行环境。导入为只读历史，不恢复原内核任务；系统 SAF 全流程尚待人工真机验收。
- 记忆为可编辑、可被模型读取的独立文件，不代表自动生成记忆管线已启用。
