## 改动

- 前台模型选择器的 DSH插件下不再展示“由DSH插件提供、部分模型暂不可用、15分钟检查、测试通过不保证……”长说明，直接保留“重新检测可用模型”入口和可用模型列表。
- 设置中的DSH分组也去掉该段及重复说明；普通供应商自己的description不受影响。
- DSH公共配置不再输出该生成说明，旧宿主仍携带description时前端也不显示。没有修改健康检测、模型/供应商身份、账号目录、推理能力或选择存储。
- 沿用已有管理检测接口，只有近期实际连通测试通过的DSH模型进入列表；未知、失败和过期模型继续隐藏，保存选择/发送前的校验保留。重新检测不等同于保证未来所有请求或工具往返必然成功。
