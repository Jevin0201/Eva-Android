# 0.0.60 界面统一与设置密度

更新日期为 2026-11-06。

## 本轮范围

依据用户确认的 HTML 信息结构实施，并按后续要求沿用 Eva 的现有主题变量、图标、字体和组件。用户授权子智能体并行处理提示词气泡、扩展页面、回答操作，主任务负责设置、集成和升级。

- 设置首页集中为账号、能力与个性化、偏好设置、应用四组。工具在标题栏的统一工具入口中完整保留。
- 记忆、钩子、备份模块停止各自向设置首页追加分组，由 settings.js 统一排列入口。业务调用继续使用现有实现。
- 设置列表的单行触摸高度为 44px，组间距为 12px。多行内容自然增高。移除外层卡片内边距，明确将设置分组重置为普通块布局，避免全局 `.group` 的 flex gap 再次叠加空白。
- 超时和浏览模式改用选择控件并接入原保存逻辑。浏览器启动页补 HTTPS 校验。长说明折叠展示。
- 技能与插件保留一个标题和插件、技能、MCP 标签，移除手机桌面侧栏与重复技能列表。搜索、来源管理、安装和已有详情能力保留。
- 插件与技能原来共用同一 settingPage，导致返回历史漏记。现按实际标签识别页面，回退依次经过 MCP、技能、插件、设置、聊天。
- 回答复制保留一个图标，移除重复操作菜单。文件摘要直接打开本轮差异，无变更和运行中不展示已完成摘要。原撤销按钮没有宿主处理器且语义易误导，已移除。
- 已发送提示词的原组件挂载容器占满可用行宽，内部气泡继续由成熟组件控制，修复短英文和中文的二次压缩。历史消息内容保持原状。
