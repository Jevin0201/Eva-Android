# OpenAI 账号额度展示 · 0.0.15

在 OpenAI / ChatGPT 原生账号页增加独立额度区域，通过 Codex `account/rateLimits/read` 读取：

- 多额度组（rateLimitsByLimitId），缺失时回退 rateLimits。
- 根据服务端 windowDurationMins 展示窗口时长，不硬编码五小时或一周。
- 已用比例、由已用比例计算的剩余比例、手机本地时区重置时间。
- 额外额度余额/不限额标记、个人支出上限与已使用量（仅服务端返回时显示，不擅自添加美元单位）。
- ordinaryUsageAllowed 单独展示，不从剩余百分比猜测是否允许调用。
- 更新时间、未登录、读取失败和字段缺失状态；缺失使用率不能显示为“剩余 100%”。退出账号后清除额度显示。

已编译、签名并安装 0.0.15。QuotaCheck 真机使用模拟数据验证多窗口、余量计算、重置时间、额外额度、未知值与失败态。没有把模拟数据作为用户真实额度。真实账号数值需用户完成授权后从服务端读取。
