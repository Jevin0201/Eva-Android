# Eva Android 0.0.70 独立安装候选

2026-11-07。目标是公开分发 APK，用户首次打开后自动部署基础环境与完整依赖，随后配置自己的大模型。独立安装、完整依赖、中断恢复和冷启动验收已通过，正在准备公开测试版发布。

## 自动部署

APK 自带经 SHA-256 校验的基础 Alpine ARM64 镜像。首次启动启动可见前台部署服务，安全解压并原子提交基础环境，然后自动安装签名 Alpine 依赖、办公渲染、Java 17/21、Android SDK、Ghidra 和 REA。完整依赖需要网络和至少 6 GiB 可用空间。系统权限通过手机控制的一键入口引导确认。

下载使用 Android 本机认证回环 CONNECT 通道，TLS 保持端到端，解决 Linux 用户态固定 DNS 在部分手机网络中不可用的问题。错误输出对本机代理认证信息做脱敏。

Ghidra 固定为 12.1.4，按已核对的官方 SHA-256 校验，从发行物中的原生源码编译 ARM64 反编译器。REA 固定为 6.8.0，包管理器保存依赖锁文件。部署包含 Java 编译执行、办公生成回读及 ARM64 真实样例的 Ghidra/REA 反编译自检，全部成功才写入就绪标记。

重复部署保留用户配置、会话、工作区与已校验下载。完整环境缺失时继续部署，不把旧的基础就绪标记作为完整就绪。配置初始化使用独占创建语义，保留已经存在的用户配置。

## 目前实测

独立 ai.eva.android.bootstrapcheck 包已实际完成系统依赖、Java 21 兼容层和 Android SDK 部署。发现固定 DNS 故障并补接 Android 网络通道，发现 Ghidra 原生编译缺少 bison 后补齐 bison、flex 和 zlib-dev。完整流程随后通过。

记录集中在 artifacts/review-20261107/distribution-*。本轮准备的临时内容集中于既有 probe/build 和独立测试包目录，原主包与数据保留。

## 许可与签名

用户明确要求非商业使用，项目自身版权代码采用未修改的 PolyForm Noncommercial 1.0.0，第三方组件许可分别保留。仓库说明采用“非商业源码公开”表述。正式签名候选使用独立的本机维护者签名密钥，材料位于 .release-signing，已排除 Git。Release 构建关闭 debuggable，移除 instrumentation 和内部测试组件，生成签名校验记录。

独立测试中实际发现并修复 Ghidra 不允许工程路径含隐藏目录的问题。隔离空目录部署已在依赖安装阶段人为终止，仅终止独立测试包，再从保留的基础环境继续部署。新增测试包在用户确认后已安装，正在通过正常首次启动页面自动部署。

## 最终独立安装验收

两个独立路径完成验收。ai.eva.android.bootstrapcheck 的隔离空目录从基础镜像开始部署，在依赖阶段人为终止后重新启动，最终完整就绪。ai.eva.android.firstinstallcheck 从新安装开始自动部署，实际错误后通过更新与重试进入完整就绪，冷启动保持就绪且不重复部署。

实际自检已覆盖 Node 执行、Python SSL/SQLite、办公四格式生成回读、Java 21 编译与三种执行模式、Android 源码生成签名 APK、ARM64 原生编译执行、Ghidra Headless 和 REA Evidence。发现 REA 需要 procps-ng 并补齐，完整自检在 Android 普通应用域内通过。全新测试包无聊天、无提供商、未登录账号；无账号代理内核初始化与临时会话通过。完成按钮已实际进入受保护的 ModelsActivity，不截取模型凭据窗口。

正式签名包为 0.0.70，关闭 debuggable，移除 instrumentation 和内部测试组件，内置项目非商业许可证。通过 v3 签名轮换将原开发签名关联至正式签名，Android 9 及以上使用新签名。已在原手机以保留数据覆盖方式升级成功，首次安装时间仍为 2026-11-02，版本与非调试标志读回通过。升级前完整会话快照已保存。

首次部署使用网络，建议预留 8 GiB 空间。手机控制仍需用户通过一键入口确认系统授权并启动 Shizuku；未安装时从 Eva 内置浏览器打开官方分发页。此次只实测一台 ARM64 Android 17 手机，后台虚拟屏最低需要 Android 14。公众版本以公开测试版形式发布，其他厂商、低版本系统及长期运行需要继续收集验证。

正式签名材料保存在本机 .release-signing，已排除 Git，不能上传。包内许可、当前部署脚本、签名链和压缩完整性均已校验。公开仓库前对当前文本与历史文本做常见凭据模式检查，历史文本未发现候选匹配；此检查范围不等于全部信息安全审计。
