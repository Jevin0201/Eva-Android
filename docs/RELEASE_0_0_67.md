# Eva Android 0.0.67 路线复用、资源调度与后台屏恢复

2026-11-06。接续用户要求的第 4、5 项升级，并修复后台屏开关自动关闭与 Eva 适配问题。

## 已实现

新增 eva_phone_route 工具。成功的 eva_phone_steps 内部回执可作为候选，保留 30 分钟，按用户明确要求保存导航路线。当前采用精确 goal 匹配，回放复用实时节点定位、条件等待和取消机制。回放返回当前观察，模型核验并提交该回合 receipt 后才增加成功计数。同一步连续两次偏离会停用。输入和敏感操作、纯编号点击不纳入路线。存储为手机私有 files/phone-routes，原子保存与进程内并发更新。

资源调度接入实际手机调用、批处理、路线回放、浏览器租约、完成、中断、内核退出及显式停止入口。资源包含主屏/后台屏、App 包名及 Android 用户、浏览器页面和保守剪贴板锁。采用原子非阻塞申请，冲突返回占用者和重试原因，避免工具串行队列阻塞。保留 Eva 当前单手机控制 owner 约束，浏览器页面可独立持有。完成和中断按 thread 与 turn 精确释放，旧回合不会释放或停止新回合。

后台屏开关改为持久化用户选择。无障碍或前台服务短暂断开时保留选择，具备权限、解锁且没有手机任务占用后在独立生命周期线程重建。恢复有节流、代际票据和创建前后核验。明确关闭开关或停止手机控制会取消选择。已选择后台屏但屏未恢复时拒绝手机操作，避免执行落到主屏。UI 同时显示用户选择与实际运行屏号/等待原因。

补齐 Eva 原生信息流中批处理、微信和路线工具的标签、详情及历史恢复。上述工具截图采用原有历史压缩策略，模型收到图像，聊天 UI 保存文字占位。
