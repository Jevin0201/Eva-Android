## 已实现

- 内核事件以既有原生通知驱动；保留自适应兜底轮询，空闲从 150 ms 逐步退让至 1 秒。每次收到通知合并旧计时器；每批达到 200 条则让出当前 JS 执行后继续读取，避免积压等待固定轮询。暂停时不跨桥读取，失败后保留重试。
- 原生队列只在取出事件时持锁，在锁外序列化 JSON，降低生产者等待。保留事件顺序、每批上限、队列溢出恢复规则。
- 内核预热的模型配置读取移入后台执行器，同一宿主的并发预热合并；失败后可以再次预热。未改变真实发送、工具授权或任务重试策略。
- 对话顶部手机按钮改为 `phone-preview`，直接显示/关闭虚拟屏悬浮预览，不再进入手机控制页面。关闭预览不停止执行任务，也不修改后台屏执行选择。预览已经启用但暂时隐藏时，点击仍尝试显示。
- 缺少悬浮窗权限时直接打开系统授权，返回当前对话后尝试恢复预览；后台屏未启用或连接不可用时提示实际状态。设置与工具里的手机控制入口保留。
- 内置浏览器按标签保存桌面模式，处理页面早期 UA、viewport 及页面动态重写；增加多标签创建、切换和关闭入口。标签栏按用户反馈缩小。
- 0.0.88 修正标签标题与关闭图标的垂直居中；关闭图标使用绘制的 X。关闭最后一个标签时关闭浏览器并返回对话，不再自动重建首页标签。0.0.88 真机已验证后台标签、当前标签和最后标签的关闭。
