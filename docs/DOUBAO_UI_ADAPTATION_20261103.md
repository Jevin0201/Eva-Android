## 取舍

| 豆包观察 / 静态事实 | 对 Eva 的价值 | 这次适配 |
| --- | --- | --- |
| 新对话大留白、能力入口靠近输入区 | 让开始任务更轻松 | 首页单一任务提示，手机控制/浏览器/文件/终端四个真实入口 |
| 侧栏能力入口在历史之前 | 不必先进入设置找能力 | 新建下方增加“技能与连接器”，保留项目树、历史、滑动删除 |

| 连接器 pending 与失败回读 | 防重复操作和假成功 | pending禁用、保存失败保留表单、完成后回读配置；旧页面响应隔离 |

| 对话/工作模式切换、推荐内容、使用人数 | Eva 现有代理已经统一处理任务；没有必要增加模式或运营内容 | 不迁移 |
| SaaS/CLI 连接目录与自动授权 | Eva 未提供同等服务集成，不能只复制卡片宣称可用 | 不迁移，不制造虚假连接器 |

## 用户审查后的撤回

用户指出技能、插件、连接器界面既未忠实借鉴豆包，也失去正式 Codex 的样子。本轮设计验收不通过，前文“适配”仅为历史实施记录，不能视为设计目标已完成。

撤回自行追加的能力页分段切换、卡片和列表视觉层；插件与技能页、统一扩展导航恢复至 02bfa93 基线；MCP 展示名称恢复，保留失败保值、防重复请求和异步页面隔离等独立功能修复。首页、草稿欢迎区修复不在这次局部撤回范围。后续需要以真实参考的页面结构和完整使用路径重新设计，不能再把文案替换与通用 CSS 视为移植完成。

撤回后的插件、技能、扩展导航、MCP、连接器健壮性、对话能力引用共6套回归通过。此基线也不是正式 Codex UI 的完整还原，不宣称设计重做完成。
