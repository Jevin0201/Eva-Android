## 设置逐页说明

1. 账号与模型：账号状态、登录/退出、自定义服务商、模型发现、测试请求、默认模型。模型来源与能力分开显示，不静态假列可用模型。
2. 执行与权限：手机控制、截图/录屏、文件访问、通知及后台执行。状态读取系统真实授权；打开系统授权页后返回自动刷新。
3. 浏览器：启动页、标签恢复、下载目录、网站权限、浏览数据清理。清理明确列出影响，不能把浏览器内容当代理指令。
4. 工作区：当前项目、导入导出、存储占用、编辑偏好。手机实际路径与 Linux 逻辑路径通过统一映射处理。
5. 外观：跟随系统/浅色/深色、文字大小；全页面统一生效并持久化。
6. 任务与通知：运行状态通知、完成提醒、取消策略、后台限制说明；不展示无实际服务支撑的开关。
7. 运行环境：初始化/更新状态、版本、磁盘占用、组件许可证与诊断。实验 PRoot 构建来源尚未完整，发布前必须补齐。
8. 数据与隐私：会话/项目导出、日志导出与脱敏、清除范围、账号和 API 凭据分开删除。

## 数据与接口约定

会话记录至少包含 conversationId/projectId/providerId/modelId/messages/draft。
工具记录至少包含 taskId/callId/toolName/arguments/state/startedAt/finishedAt/result/error。
事件按 seq 排序并去重；工具输出与最终助手文本分开保存。密钥只经原生凭据服务读取，不放入会话、网页 DOM、日志或模型提示词。
