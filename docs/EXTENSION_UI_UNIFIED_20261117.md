# 技能与插件整页统一（2026-11-17）

本轮纠正上次仅统一局部按钮外观的范围错误，以插件页为基准统一插件、技能、MCP 三页。

## 完成内容

- 三页使用同一标题、标签导航、搜索/刷新/管理/添加工具栏、筛选栏、分组标题、图标、列表行、尾部操作、空状态与错误样式。MCP 的旧展开卡片改为列表行和详情弹层；连接测试、授权、资源、密钥、启停、删除保留。
- 三页都挂载现有 `EvaPluginAddHost` 原添加组件，不再给技能页绑定旧管理弹窗、给 MCP 绑定页内表单。共用创建插件、添加插件市场、上传插件压缩包、添加自定义 MCP 服务器四项及对应原操作流程。独立技能导入仍从管理入口进入，本地 STDIO 配置在 MCP 管理中保留。
- 保留同一页的添加组件节点，后台目录更新不再销毁已打开的添加菜单。页面切换和返回仍关闭对应弹层。
- 技能页移除“插件技能”独立分类；插件内部技能按归属从独立目录与 @/$ 候选隐藏，独立英文技能保留。未删除文件或停用内核技能，正式 Codex 证据与边界见 [可见性记录](PLUGIN_SKILL_VISIBILITY_20261117.md)。
- 修复迁移源与打包资源的历史偏差，`android-head.js + adapted-renderer.js + android-tail.js` 与实际 `desktop-extensions.js` 完全一致，防止再生成恢复旧 UI。
