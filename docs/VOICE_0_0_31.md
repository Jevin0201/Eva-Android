# 0.0.31-voice：等用户说完、明确开关与摄像头光圈

2026-11-02，仍为测试版。保留现有代理、模型、权限模式、聊天记录及 0.0.30 的相近发音词表，无新增第三方依赖。

## 对话边界

此前把识别器的短停顿直接当作提交条件，会把唤醒结束或思考停顿误当成整条指令结束。现在分开处理唤醒、收音、结束判断和发送：

1. 唤醒只进入 listening，播放短提示音、双段振动和蓝色波纹，不提交任务。唤醒词/填充词在自身端点清掉，最多留 20 秒等第一条有效语音。
2. 流式识别持续收集内容。默认静音确认时间 3 秒，可选择 2/3/5 秒；识别器先检测 1.2 秒端点，再累计剩余时间，恢复讲话会取消确认计时。
3. 明显残句（如“我想让你”“帮我打开”“打开相册然后”）不自动发送；暂停 12 秒仍不完整时保留到待确认页面，可继续补充、修改发送或丢弃。
4. 只有候选指令、正常静音结束且开启自动发送，才进入现有代理。60 秒录音上限不是说完的证据，截断内容必须待确认。空白、单独唤醒词不发送。
5. “说完了”或页面/通知的完成按钮可主动结束。关闭“说完自动发送”后，主动结束也保留待确认，必须点击确认发送。

`VoiceCommandPolicy` 是保守的中文规则判断，**不是完整语义模型**。例如“打开相册”本身可执行，若用户停顿超过所选时间后还想补条件，系统仍可能提前提交。需要较长思考时间时选择 5 秒；需要保证每次先检查时关闭自动发送。尚未达到小爱级自然轮替和广泛口音鲁棒性。

## 界面

- 总开关由实际服务状态驱动，有“开/关”和醒目的“已开启/已关闭”；直接听写、提示音、振动、预览、自动发送均为开关。
- 每次回到页面及前台刷新时检查麦克风、悬浮窗、通知通道与无障碍授权；已授权显示 ✓，未授权显示 ？。手机控制单独说明是否真正开启。
- 移除旧文字弹窗，使用摄像头附近的透明波纹光圈；根据 display cutout 定位，可上下左右微调。绿色待唤醒、蓝色听写、紫色执行、橙色待确认，听写文字留在页面。
- Android 应用悬浮层不能保证覆盖厂商系统灵动岛。本机系统媒体胶囊展开时会遮挡部分光圈；位置微调可避让。不能将此称为已经接入小米原生灵动岛 API。
- 光圈不接收触摸，透明度 0.75；状态栏和页面操作不被光圈截获。

Android 窗口层级参考：[WindowManager.LayoutParams](https://developer.android.com/reference/android/view/WindowManager.LayoutParams)、[Display cutout](https://developer.android.com/develop/ui/views/layout/display-cutout)。另尝试了已授权无障碍窗口层，本机系统胶囊仍遮挡，最终保留普通应用悬浮层。

## 实测与边界

- M332BF / Android API 37，覆盖安装版本码 31，原有数据保留。APK：`artifacts/eva-android-0.0.31-voice.apk`。
- `VoiceCheck mode=guards`：11 类文本、完成标记、唤醒/残句/不确定内容/录音上限不提交、关闭自动发送不能被完成按钮绕过、真实服务开关和权限标记。通过。
- `mode=delayed`：扬声器播“你好艾瓦”，等待 5 秒保持监听且不提交，再播“打开相册”，识别成功。此模式仅诊断，不调用代理。曾出现合成音未检出唤醒，增加收音稳定等待后的延迟测试通过，但后续残句测试首轮仍未检出；原因尚未完全定位，不能声称唤醒稳定性已解决。
- `mode=fragments`：直接听写识别“我想让你”，等待 5 秒仍保持监听，补说“打开相册”得到“我想让你打开相册”；诊断不提交任务。通过。该项隔离测试听写轮替，不计入唤醒成功率。
- `mode=gallery`：直接听写采集“打开相册”，真实提交配置的云端代理，观察到前台 `com.miui.gallery`，任务结束。线程 `01a19ce8-89a5-7820-b9bd-aaf230ab66ae`。测试检查前台包名，不检查相册图片内容。
- `mode=service`：原生模型、麦克风前台服务、跨应用光圈与关闭通过；查看截图确认位置，同时发现系统胶囊遮挡限制。此模式会主动打开系统设置检查跨应用显示，**与“打开相册”的执行无关**。
- JavaScript 的语音历史、设置路由、聊天草稿与权限回归通过。摄像头光圈与开关截图在 `artifacts/voice-0.0.31-*.png`。

听写和唤醒测试音由 Windows Huihui 合成，不代表真人、多噪声、多距离测试；后台长时间、电量、锁屏、通话及蓝牙还需验收。复现延迟测试：运行 `tools/voice-delay-fixtures.ps1`，将对应 WAV 放到应用私有 `files/`，执行 `adb shell am instrument -w -e mode delayed ai.eva.android.probe/.VoiceCheck`。结束后关闭语音服务，不留下测试录音会话。
