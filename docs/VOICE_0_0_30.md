# 0.0.30-voice：相近读法唤醒

2026-11-02。针对用户反馈“你好艾瓦”偶尔无法唤醒，在 0.0.29 基础上扩充音素词表。

- 兼容“你好艾瓦、你好艾娃、你好爱娃、你好埃瓦、你好伊娃”，保留“你好 Eva”英语发音路径。
- 兼容“你好”中“你”的第三声及连读变调后的第二声，共 12 条音素路径。同音汉字本身不会产生新的声学路径，真正增加的是不同声调、轻声及首音。
- 保留完整“你好…”前缀，未增加单独“艾瓦”或普通“你好”的唤醒。阈值仍为 0.30、关键词分数仍为 1.5，先隔离读法覆盖的改进，不全面降低检测门槛。
- `probe/voice-keywords.txt` 是唯一配置源，构建和依赖准备脚本同步到 assets。启动引擎时刷新私有目录的关键词文件，避免升级后继续使用旧缓存；大模型文件不重复复制。
- 语音设置页面展示兼容读法。包名和签名保留，版本码 30，原有账号、聊天与工作区不清除。

## 验证

- APK 编译、签名验证及 M332BF 真机覆盖安装成功。
- `VoiceCheck mode=variants`：Windows Huihui 合成 5 种中文读法 × 两档语速，10/10 检出；5 条不相关语句全部未触发。测试只解码文件，不发送任务、不播放声音。记录：`artifacts/voice-variants-0.0.30.txt`。
- 负样本：“你好小王”“今天的天气怎么样”“帮我打开相册”“我爱我的家”“你好大家好”。这些样本不能代表真实环境误唤醒率。
- `VoiceCheck mode=acoustic`：手机扬声器→麦克风真实采音，唤醒后听写结果为“打开相册”，跨 App 浮层与关闭通过，诊断模式不提交代理任务。记录：`artifacts/voice-acoustic-0.0.30.txt`。
- 测试结束后关闭语音模式并打开语音设置页，需用户点击开启再试。

真人口音、远距离、噪声、不同音量仍待用户试用。此次改动扩大可接受的发音范围，不能保证每次唤醒，也不能把少量合成样本结果当作总体准确率。

复现：`powershell.exe -File tools/voice-variants-fixtures.ps1` 生成 15 个 16 kHz 单声道测试 WAV，将其放入应用私有 `files/voice-variants/` 后运行 `adb shell am instrument -w -e mode variants ai.eva.android.probe/.VoiceCheck`。完整依赖与原架构见 [0.0.29 记录](VOICE_0_0_29.md)。
