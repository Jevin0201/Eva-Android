## 独立安装与公开测试版

当前源码已将首次设置拆为两步：确认安装必备环境，然后选择办公、开发或媒体能力，也可全部跳过直接配置模型。基础环境继续随 APK 提供；联网安装必备依赖后即可使用。REA 与 Ghidra 分别放在专业工具中，不强制安装。设置中的「能力与组件」可继续选装；聊天使用缺失组件时通过确认入口安装后继续原任务。新流程已在独立真机包中通过核心首次部署、冷启动、跳过选装、中断重试及按需安装确认检查；原正式应用未被覆盖。实现与检查范围见 [分层部署记录](../docs/MODULAR_SETUP_20261107.md)。原 0.0.70 全量部署的独立安装与中断恢复实测仅代表该历史版本。

安装期间会显示进度与错误，可取消并重试。模型凭据由用户自行添加。手机控制需要通过一键启用入口完成 Android 系统授权。后台虚拟屏需要 Android 14 或更新版本，基础 ARM64 运行环境要求 Android 9 或更新版本。

已实测 ARM64 Android 17，当前按公开测试版范围提供。首次安装、错误恢复和公开分发条件见 [独立安装验收记录](../docs/RELEASE_0_0_70.md)。实际验收范围以该记录为准。
