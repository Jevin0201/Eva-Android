# Eva Android UI 设计预览

入口：`index.html`。无第三方依赖、无需联网，可直接用浏览器打开。宽屏显示评审目录、手机预览与设计说明；手机宽度仅显示产品界面。

本轮仅生成 HTML 交互设计稿，没有修改应用 UI 或安装 APK。53 个页面状态，覆盖侧边栏、设置及子页、关联工具，以及统一弹窗。数据均为示例；按钮仅演示跳转、选择、反馈，不连接账号、不执行设备或文件操作。部分列表仅为结构样例，浏览器内容管理等后续仍需深化；正式迁移应复用现有状态与业务逻辑。

## 审查依据与边界

- 在浏览器中逐页读取并截图现有 15 个 Web 设置路由：settings、models、permissions、execution、browser、storage、appearance、about、tools、privacy、memories、hooks、plugins、skills、mcp。使用模拟 Android 桥接，因此账号、插件、组件状态不代表真机；见 `artifacts/ui-redesign-20261108/current-pages.json` 和 `current-contact-sheet.jpg`。
- 读取 `app.js`、设置覆盖层、模型面板、扩展管理、记忆和钩子源文件，核对侧栏与弹窗入口。
- 原生 Activity 的页面标题和操作文案逐文件盘点保存在 `artifacts/ui-redesign-20261108/native-page-inventory.json`。本轮未在真机逐一操作原生页，不能把源码盘点称作真机浏览验收。
- 不含第三方网站、Android 系统授权界面或文档内容自身的重新设计。

## 设计安排

- 白底、暖灰辅助面、细线图标与深色主按钮，延续主对话界面的视觉语言。
- 设置按连接与能力、偏好、更多分组；工具另设聚合页，侧栏以项目和对话为中心。
- 常规配置放在页面中；选择和快捷新增使用底部面板；长表单进入独立页；删除使用居中确认。
- 模型连接、文本测试与工具测试区分，保留可能计费的操作说明；备份保留只读历史和不包含文件/凭据的边界。

## 验证与清理

使用本机 Chrome / Playwright 检查 53 个页面，1440px 评审界面与 320px、390px 手机布局无横向溢出、无 JavaScript 页面异常；深色主题与部分页面截图已保存。不是应用业务验收。

临时与证据集中于 `artifacts/ui-redesign-20261108/`。原页面单独截图合并为联系表后已删除 15 张冗余 PNG，保留源页面文字、原生清单和验证记录；保留 HTML 及设计截图供后续评审。项目其他既有构建、APK、依赖与用途未明文件均未删除。
